# Short Exporter

Short Exporter is a Next.js and TypeScript PWA that turns HTML animations into vertical MP4 videos in desktop Chrome and Edge. Preview your animation and export it directly in your browser.

## Local setup

```sh
npm ci
npm run dev
```

Open [localhost:3000](http://localhost:3000).
